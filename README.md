### 🔭 What I'm into

I'm into systems software — the layer where you're close enough to the machine that every decision about memory, concurrency, and I/O actually matters. I like picking a complex system apart (browser engines, HTTP servers, interpreters) and rebuilding the pieces myself to really understand them.

Most recently I've been building **TRF Flow Terminal**, a serverless pipeline (Go on AWS Lambda) that ingests and classifies live equity trade data across multiple tickers, separating lit-exchange volume from off-exchange flow. Getting it fast was the fun part — an S3-backed caching and incremental-polling layer brought cold-request latency down from 30s to 1s.
